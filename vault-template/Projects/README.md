# Projects

Active work with an outcome and an end date. One folder per project:

```
Projects/<Project>/<Project>.md          project note (from Templates/Project.md)
Projects/<Project>/Meetings/YYYY-MM-DD <Title>.md
Projects/<Project>/Decisions/YYYY-MM-DD <Title>.md
```

Created by the `project-intake` skill; closed and moved to `Archive/` by `project-closeout`.
