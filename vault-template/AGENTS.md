# Working in this vault

You are working inside the Operator's PARA vault. Read `README.md` for the folder layout.

- New project notes come from `Templates/Project.md`, meeting notes from `Templates/Meeting Note.md`, decisions from `Templates/Decision.md`, weekly reports from `Templates/Weekly Report.md`.
- Keep frontmatter fields (`status`, `owner`, `due`, `updated`) current when you change a note, and set `updated` to today.
- Do not edit `Templates/` or this file unless the owner asks.
- Writes outside your own report notes follow draft, owner approves, write.
