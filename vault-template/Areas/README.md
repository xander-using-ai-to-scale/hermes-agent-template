# Areas

Ongoing responsibilities that never "finish" (operations, team, finance, a standing client relationship).

- `Reports/Daily/YYYY-MM-DD.md` — daily status briefs
- `Reports/Weekly/YYYY-Www.md` — weekly reports (ISO week)
- `Reports/Monthly/YYYY-MM.md` — monthly reports
- `Meetings/` — meetings that belong to no single project
